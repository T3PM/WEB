หลักสูตรที่เปิดสอน

1. ระดับประกาศนียบัตรวิชาชีพ (ปวช.)

สาขาวิชา: เทคโนโลยีสารสนเทศ

ระยะเวลาศึกษา: 3 ปี

รายละเอียด: เน้นการปูพื้นฐานด้านคอมพิวเตอร์ ระบบปฏิบัติการ เบื้องต้น การเขียนโปรแกรมเบื้องต้น กราฟิกดีไซน์ และระบบเครือข่ายพื้นฐาน

  • การเขียนโปรแกรมภาษา C, Python
  • การสร้างเว็บไซต์เบื้องต้น (HTML, CSS)
  • งานกราฟิก (Photoshop, Illustrator)
  • การประกอบและซ่อมบำรุงคอมพิวเตอร์

2. ระดับประกาศนียบัตรวิชาชีพชั้นสูง (ปวส.)

สาขาวิชา: เทคโนโลยีสารสนเทศ

ระยะเวลาศึกษา: 2 ปี

รายละเอียด: เน้นทักษะขั้นสูงเฉพาะทาง การพัฒนาระบบฐานข้อมูล การพัฒนาแอปพลิเคชันบนมือถือ และระบบเครือข่ายขั้นสูง

  • การพัฒนา Web Application (Full Stack)
  • การจัดการฐานข้อมูล (Database Management)
  • การพัฒนา Mobile Application
  • IoT (Internet of Things)
